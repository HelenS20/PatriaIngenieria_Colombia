# Capa de datos futura

Esta carpeta replica el punto de extensión del proyecto de referencia. Cuando se active Convex, aquí vivirán el esquema y las funciones de datos.

Módulos previstos:

- `jobs`: vacantes publicadas y estado.
- `jobApplications`: candidatos, hojas de vida y flujo de Talento Humano.
- `news`: publicaciones del blog.
- `clientPortal`: usuarios, documentos y solicitudes del portal de clientes.

No se incluyen credenciales ni datos personales en esta maqueta.
